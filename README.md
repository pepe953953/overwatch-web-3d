# 🎮 3D 오버워치 웹 게임 (Overwatch 3D Web)

Three.js와 Web Audio API로 구현된 풀 3D 브라우저 기반 오버워치 웹 게임입니다. 오버워치 특유의 스타일리시한 HUD, 타격감, 영웅별 무기/스킬 메커니즘, 그리고 훈련장 맵이 완벽하게 구현되어 있습니다.

---

## 🚀 빠른 실행 방법

이미 로컬 개발 서버가 백그라운드에서 실행 중입니다:
- **접속 주소**: [http://localhost:5173/](http://localhost:5173/)

추후 다시 실행하려면 터미널에서 다음 명령어를 입력하세요:
```bash
npm run dev
```

프로덕션 빌드:
```bash
npm run build
```

## 🦸‍♂️ 플레이 가능한 영웅 3종

### 1. 🪖 솔저: 76 (Soldier: 76)
- **기본 사격 (좌클릭)**: 펄스 소총 (25발, 빠른 연사와 탄퍼짐)
- **보조 사격 (우클릭)**: 나선 로켓 (Helix Rockets) - 직격 120 / 광역 40 폭발 피해
- **기술 1 [Shift]**: 질주 (Sprint) - 이동 속도 55% 증가 (사격 시 자동 해제)
- **기술 2 [E]**: 생체장 (Biotic Field) - 바닥에 범위 치유 장판 설치 (초당 40 HP 회복)
- **궁극기 [Q]**: 전술 조준경 (Tactical Visor) - *"목표를 포착했다!"* 화면 내 적 자동 조준 락온 & 초고속 재장전

### 2. ⚡ 트레이서 (Tracer)
- **기본 사격 (좌클릭)**: 펄스 쌍권총 (40발, 초당 20발의 초고속 난사)
- **기술 1 [Shift / 우클릭]**: 점멸 (Blink) - 이동 방향으로 8.5m 순간이동 (최대 3회 충전)
- **기술 2 [E]**: 시간 역행 (Recall) - 3초 전의 위치와 체력으로 되돌아가며 탄약 즉시 완충
- **궁극기 [Q]**: 펄스 폭탄 (Pulse Bomb) - *"폭탄 받아라!"* 벽이나 적에게 부착되는 폭탄 투척 (350 대미지)

### 3. 🥷 겐지 (Genji)
- **기본 사격 (좌클릭)**: 수리검 3연발 (27 대미지, 헤드샷 54)
- **보조 사격 (우클릭)**: 수리검 부채꼴 (3발 동시 투척)
- **패시브 [Space]**: 이단 점프 (공중에서 스페이스바 한 번 더)
- **기술 1 [Shift]**: 질풍참 (Swift Strike) - 전방으로 14m 돌진 베기 (50 대미지). **적 처치 시 쿨타임 즉시 초기화!**
- **기술 2 [E]**: 튕겨내기 (Deflect) - 2초간 적의 투사체를 조준점 방향으로 튕겨냄
- **궁극기 [Q]**: 용검 (Dragonblade) - *"류진노 켄오 쿠라에!"* 네온 그린 카타나를 뽑아 광역 검기 베기 (일격당 110 대미지)

## 🎯 게임 시스템 & 전장 특징

1. **오버워치 HUD & 연출**
   - 기울어진 특유의 미래지향적 인터페이스
   - 체력바 세그먼트 및 저체력 경고 비네트
   - 0~100% 원형 궁극기 게이지 (100% 도달 시 네온 화염 펄스)
   - 일반 히트마커(흰색) 및 헤드샷 치명타 히트마커(빨간색 대형 X)
   - 처치 시 빨간색 해골 배너와 오버워치 시그니처 사운드
   - 우측 상단 킬 피드 (Kill Feed)
   - `[Tab]` 키로 확인 가능한 점수판 (처치, 피해량, 치유량, 명중률)

2. **Web Audio API 절차적 사운드 엔진**
   - 별도 음원 파일 다운로드 없이 브라우저 내에서 즉각 합성되는 무기 발사음, 재장전, 궁극기 사운드
   - 오버워치 특유의 청량한 헤드샷 "띵(Dink)!" 사운드 및 처치 팡파르

3. **다양한 훈련용 옴닉 봇**
   - **머리 중앙 빨간 광학 렌즈**: 치명타(헤드샷) 피격 판정 (2.0배 대미지)
   - **고정형 연습 봇**: 사격 및 집탄 테스트용
   - **순찰형 봇**: 레일을 따라 왕복 이동
   - **전투형 옴닉 봇**: 플레이어를 향해 붉은 에너지 탄환을 발사 (피하거나 겐지의 튕겨내기로 반사 가능!)
   - **비행 드론 봇**: 공중에서 부유하며 움직이는 에임 트래킹 봇

4. **전장 기믹**
   - **점프대 (Jump Pad)**: 발판 위에 서면 공중으로 높이 도약
   - **소형/대형 힐팩 (Health Packs)**: +75 HP / +250 HP 회복 및 리스폰 쿨다운
   - **거점 A (Capture Point A)**: 거점 원 안에 머무르면 0%에서 100%까지 점령 진행
